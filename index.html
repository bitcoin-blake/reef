About Reef

Reef 0.1 · a Bitcoin node in a browser tab, for txbt4, the BLAKE2b testnet4.

It looks like Knots and runs a chain Knots defined, but it is not Knots. The tab fetches the fork-point UTXO snapshot, recomputes its hashes, validates every block since the fork and follows the chain tip. The wallet is one key kept in this tab.

Back up the wallet key

The key is the wallet: anyone who has it can spend the coins, and if it is lost the coins are lost. It lives only in this browser; clearing site data, or the browser freeing space, removes it.

Keep a copy somewhere only you can read: a password manager, or the file below on another disk.

Other wallets: import the descriptor (rawtr). The address is the key's own output, not a BIP 86 tr() address, so importing the WIF as tr() shows a different, empty address.
Welcome to Reef

Reef is a Bitcoin node and wallet that runs in this tab, on txbt4, a test network (the BLAKE2b testnet4). Its coins are test coins with no value.

To start, the tab downloads the chain's state at block 150,307 (830 MB), checks it, and then validates every block since. That takes about a minute on a fast connection and longer on a slow one; it is kept for next time, and resumes if interrupted. Avoid starting on a metered connection.

Nothing leaves the tab except requests for the chain and, when you pay, the signed payment. The wallet key is made here and stays in this browser: back it up before you receive coins.
